# API Reference

Full interactive documentation is auto-generated by FastAPI at `/docs` (Swagger) and
`/redoc`. This page covers conventions that apply across all endpoints.

## Versioning

All endpoints are under `/api/v1`.

## Auth

`POST /api/v1/auth/register` creates a new tenant + admin user and returns a JWT.
`POST /api/v1/auth/login` returns a JWT for an existing user. Every other endpoint
requires `Authorization: Bearer <token>`; `tenant_id` is derived from the token, never
accepted from the client.

## Response envelope

Success:

```json
{ "success": true, "data": { }, "meta": { } }
```

Error:

```json
{ "success": false, "error": { "code": "DATASET_NOT_FOUND", "message": "Dataset was not found" } }
```

## Pagination

List endpoints accept `page` (default 1) and `page_size` (default 50, max 500) and
return pagination metadata (`page`, `page_size`, `total`, `total_pages`) in `meta`.

## Errors

Errors never leak stack traces. Unhandled exceptions are logged internally with full
detail and returned to the client as a generic `500 INTERNAL_ERROR`. Expected error
conditions (not found, validation, auth) return the appropriate 4xx status with a
specific `code` the frontend can branch on.
